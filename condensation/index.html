计算公式说明

露点（Magnus 近似）：由 Ta、RH 计算 Td。

热流：q = (Ta − Ti) / (1/ho + δf/λf + δv/λv + 1/hi)

外表面温度：Ts = Ta − q / ho

判定：Ts > Td + Δ → 满足（防凝露）；否则不满足。

厚度输入为 mm，计算时换算为 m。无 VIP 时 δv 项为 0。

单位：温度 °C · 厚度 mm · λ 为 W/(m·K) · 静态页，可 GitHub Pages 公开
